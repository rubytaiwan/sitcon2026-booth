讓你的社員在一個下午，用 AI + Ruby on Rails 做出第一個 Web App。

我們提供什麼

免費到校授課 Ruby Taiwan 社群講師到你的社團上一堂 3.5 小時的實作課
零安裝開發環境 使用 GitHub Codespaces，學員只需要瀏覽器和 GitHub 帳號
AI 輔助教學 課程融入 AI 工具，學員跟 AI 對話設計 App、生成前端 UI
完整教材與 Prompt 卡 Step-by-step 教材 + AI Prompt 範本，課後可自行複習
成果展示 課程結束時每位學員都有一個能動的 Web App，可直接截圖分享

兩種課程版本

版本 A — 大學社團

大學本科生版

  • 對象：有 Python / C 基礎，未碰過 Web 的本科生
  • 內容：HTTP 概念 → Rails scaffold → AI 前端美化 → 選修功能 → 成果展示
成果：有 CRUD 功能、AI 美化前端的 Web App
版本 B — 高中社團

高中生版

  • 對象：程式基礎薄弱或零基礎的高中生
  • 內容：Ruby 初體驗 → 跟 AI 聊 App 點子 → Rails 魔法時刻 → AI 美化 → 個人化
成果：客製化個人小網站，有 AI 設計的外觀

Ruby Taiwan 社團課程合作計畫 2026 — 3.5 小時實作課

版本 A：大學本科生版（3.5 小時）

時間 階段 內容
0:00–0:10開場Ruby Taiwan 社群介紹、課程目標、確認 Codespace 環境
0:10–0:25Web 怎麼運作的瀏覽器 DevTools 實際觀察 HTTP Request / Response
0:25–0:45跟 AI 聊你的 App用 Prompt 引導卡，讓 AI 幫你設計 Model 和 scaffold 指令
0:45–1:10Rails 起手式執行 scaffold → db:migrate → server → 第一次看到自己的 App！
1:10–1:20休息—
1:20–1:45理解並客製化認識 MVC 架構，修改 routes 和 view
1:45–2:35AI 前端美化截圖 → 用 AI 生成 Tailwind CSS → 貼回 view → 反覆調整
2:35–2:45休息—
2:45–3:10加分功能（自選）圖片上傳 / 資料驗證 / AI 輔助加搜尋功能
3:10–3:30Show & Tell成果展示 + 加入社群

版本 B：高中生版（3.5 小時）

時間 階段 內容
0:00–0:10開場Ruby Taiwan 社群介紹、課程目標、確認 Codespace 環境
0:10–0:25Ruby 初體驗irb 互動："hello".reverse、5.times { puts "..." }，感受 Ruby 的對話感
0:25–0:45跟 AI 聊你的 App更具體的 Prompt 範本，提供靈感清單，助教主動協助
0:45–1:10魔法時刻跑 scaffold → 看到 App 能動。強調「一行指令 = 一個 App」
1:10–1:20休息—
1:20–1:40改改看！改文字 → 存檔 → 重整 → 看到變化。建立改 code 的肌肉記憶
1:40–2:30AI 前端美化助教 live demo → 學員用 Prompt 卡操作 → 只需改「風格」和「顏色」
2:30–2:40休息—
2:40–3:05讓它更像你的用 AI 寫「關於」頁面文案 + 新增 about 頁面（三步驟）
3:05–3:30成果分享截圖上傳 Discord → 票選最佳命名獎、最佳設計獎
【師資】Ruby Taiwan 社群志工講師，每場配置 1 位主講 + 每 4–5 人 1 位助教
【費用】完全免費（由 Ruby Taiwan 社群支持）
【場地】貴社團提供教室即可，需有網路和投影設備
【人數】建議 10–25 人（可依社團規模調整）
【技術需求】學員自備筆電 + GitHub 帳號（課前準備）
課程融入 AI 工具的原因
不是為了趕流行，而是因為「描述需求 → AI 生成 code → 理解並調整」這個工作流，正是 2026 年軟體開發的日常。我們希望學員從第一天就學會「跟 AI 協作」的正確姿勢。
